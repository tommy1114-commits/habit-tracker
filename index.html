🚀 如何放上 GitHub 與開啟 GitHub Pages？

  1. 在 GitHub 建立一個新儲存庫（如 habit-tracker）。
  2. 將本專案目錄中的檔案上傳至儲存庫根目錄。
  3. 到儲存庫的 Settings ➔ Pages，將 Branch 設為 main 並儲存。
  4. 數分鐘後即可獲得專屬網址，手機與電腦隨時打卡！詳細步驟請見 README.md。
